# GIS本科课程体系拓展资料

## 写在前面

我又回来啦~虽然人已经毕业，给大家的代码仓库还在更新ing。

好快啊，本科四年GIS已经结束了。那么我在这四年里，学到了哪些关于计算机的知识呢？

**计院的课程大概有这些：**

1. C程序设计基础，程序设计专题（23级以后叫C程序设计基础及实验），是打基础的好课，但在GIS领域用处不大。仓库目录：[C语言程序设计](https://git.zju.edu.cn/3200104696/C-programming)。
2. 离散数学及其应用，计算机的数学基础。仓库目录：[离散数学](https://git.zju.edu.cn/3200104696/discrete-math)。
3. 面向对象程序设计，虽然学的是C++，但是面向对象的思想在GIS领域会很吃香。仓库目录：[面向对象程序设计](https://git.zju.edu.cn/3200104696/objected-oriented-programming)。
4. 数据结构，GIS算法的基础知识。虽然GIS算法比这个复杂得多，但基础的数据结构总要打扎实。仓库目录：[数据结构](https://git.zju.edu.cn/3200104696/data-structure)。
5. 计算机图形学，GIS中WebGIS的一大研究方向。仓库目录：[计算机图形学](https://git.zju.edu.cn/3200104696/computer-graphics)。

**地科院的课程大概有这些：**

1. 遥感数字图像处理，C++代码基本上是抄的，期末考考完算法差不多就忘记了，而且大家一般不会在GIS领域的科研中使用C++，学习效果不佳。
2. GIS应用开发，事情比较多，但确实能有收获，能给自己一些Project的经验，个人认为是GIS专业最有用的一门课。~~（接下来我可能要做这门课的助教，和森森老师一起进行课程改革研究）~~。仓库目录：[GIS应用开发](https://git.zju.edu.cn/3200104696/GIS_Application_Development)。
3. 地理空间数据库，超难，而且确实实用，数据库和地理数据库都是现今流行的东西。仓库目录：[地理空间数据库](https://git.zju.edu.cn/3200104696/geospatial-database)。
4. 地球科学大数据，只讲理论缺乏实践的典型，学了理论不知道怎么用到科研中，学习效果不佳。仓库目录：[地球科学大数据](https://git.zju.edu.cn/3200104696/big_data/-/tree/Geography?ref_type=heads)。

其实大家会发现这样一个问题，就是**地科院开的GIS方面的关于算法领域的专业课，全都有待提升。至少20级是这样的。我在做毕业论文的时候就感受到，机器学习和深度学习这块的知识严重欠缺，要么就是根本不知道用什么算法，要么就是知道用哪个算法但不会调Python库，反正毕设做的很头疼。我们班别的同学很多也有这样的情况。出现这样的情况原因很简单，因为我们的算法课要么就是底层的代码在那边抄（遥感数字图像处理 C++），要么就是简单提一下而不深入挖掘（地球科学大数据），实际的案例也非常缺乏。更没有课程系统教过我们怎么用PyTorch，怎么用scikit-learn这样的工具包。**

不过**很感谢学院的张丰老师接受了我的建议，在21级之后的培养方案里面添加了“人工智能基础”课程**，及时解决了大家的这个问题。我这个项目就是帮助大家应用这门课程知识的。

至于我为什么要做这个，实际上就是暑假期间在实验室的时候，老师没给多少任务，然后我就很空。可是，在看文献的过程中，我发现自己对于文献中代码、模型的理解和运用能力很差，经常看不懂或者无法实现。这应该是自己在本科阶段学习过程中实践基础薄弱引发的问题。于是我对比了一下后面几届的培养方案，发现这门“人工智能基础”的课程已经被加到了培养方案里，而且我们班有同学作为个性课程上过。我问他们借了教材，初看了几眼发现这个教材编的挺好的——有算法的讲解，以及后面的习题。要知道，我的数据结构能拿到满绩完全就是勤能补拙——一方面靠看书、刷题和总结错题来练，一方面把学到的所有算法都用代码敲了一遍。既然我现在感觉到自己在人工智能和机器学习领域的知识是如此的薄弱和不成体系，我就干脆打算花一整个暑假把《人工智能导论》这本书给啃下来。

## 这个项目有什么

我曾经考虑过要不要用C或C++把书里提到的所有代码底层全部都敲一遍，但后来我还是选择放弃了。我承认我的代码能力可能确实不如GIS的某些大佬，让我手搓这些算法的速度实在是太慢，这样学效率实在太低。我第三章就是这么学的，结果第三章学了一个月还没学完，这样下去我很难在开学前啃完这本书。于是我只能更改计划，把读书、做习题和调库结合，对于每一个算法，通过阅读教材了解一下它是怎么运作的，适用于什么场合和环境，然后使用scikit-learn之类的库调用一下做一个简单的实现就行，这样就大概知道这个算法用在哪里、怎么用、用了有什么效果。最后再结合每一章的课后习题复习一下这些算法，大脑里面基本上就能有一个机器学习和深度学习的知识体系。

所以，这个项目的目的就是为了把那些课里面学到的零零散散的机器学习知识整理成一个体系，然后对于每个知识点提供调库的代码实现。

在此基础上，苏老师讲的遥感数字图像处理里面实际上还讲过一些图像处理的机器学习算法，这些算法也会作为附加内容总结在这个项目里。具体见RSEx文件夹，里面的内容与”遥感数字图像处理“的实习相对应。

现在有AI和github copilot就是方便，我所有的代码可以让copilot帮我生成，一边读代码一边理解算法，还能直观的看到结果。

希望大家看了这些东西之后能够真正把机器学习的有关知识应用到日常的学习和科研中，而不是单纯的抄抄代码，背背概念，解决水课的开卷考试。加油！
